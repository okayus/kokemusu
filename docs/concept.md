# コンセプト

## 名前の由来 ── なぜ「苔むす」か

「苔むす（苔生す）」は、長い時間をかけて苔が生え、覆っていくこと。
君が代の一節「さざれ石の巌となりて **苔のむすまで**」── 小さな石が寄り集まって大きな岩となり、
そこに苔が生すほどの **悠久の時間の積み重ね** を表す言葉。

このアプリの本質はまさにそれ。

- 1回の投稿は、ごく小さな「苔片」。それ単体では何でもない。
- しかし毎日少しずつ積み重なると、いつのまにかタグ（石）の上に苔がびっしりと生す。
- 苔は派手ではない。静かに、誰に見せるでもなく、自分のペースで育つ。
- ふと振り返ったとき、「こんなに積み上がっていたのか」と気づく ── それが苔むす。

派手な成長曲線ではなく、**静かな堆積** を肯定するのがこのアプリの思想。

## メタファー設計

| アプリの要素 | 苔のメタファー |
| --- | --- |
| 投稿（1回） | 胞子・苔片 |
| タグ | 苔が生す対象（石・地面） |
| タグの蓄積量 | 苔の生え具合（薄い → びっしり） |
| 継続日数（ストリーク） | 苔の瑞々しさ |
| 長期間放置されたタグ | 乾いて枯れかけた苔（また書けば蘇る） |
| 全体ビュー | 苔の庭 |

このメタファーは UI の見た目（色・質感・アニメーション）と可視化（[visualization.md](visualization.md)）に直結させる。

## コア体験（誰が・いつ・どう使う）

1. **思いついた瞬間に書く**
   英語学習で覚えた単語、TypeScript で詰まった点と解決、相場メモ、ふとした考え ──
   ツイートするのと同じ気軽さで、1日に何度でも放り込む。

2. **タグを付けて分類する**
   `英語` `typescript` `ファイナンス` のように、自分の関心領域でタグ付け。
   後から「このテーマで自分は何をしてきたか」を辿る軸になる。

3. **積み上がりを眺める**
   週末や月末、あるいは何となく開いたとき、タグ別の苔（ヒートマップ・累積グラフ）を眺めて、
   自分の歩みを実感する。モチベーションにも、記録にもなる。

## 設計上の価値観

- **摩擦ゼロの投稿**: 投稿までのクリック数・思考コストを極限まで減らす。キーボードショートカット重視。
- **後から育つ分類**: 投稿時にタグを完璧に決めなくていい。後でタグの整理・統合ができる。
- **所有と静けさ**: 自分のデータは自分のもの。外向きの機能（共有・公開・分析送信）は一切作らない。
- **長く使える地味さ**: 流行りの演出より、10年使い続けられる落ち着いた体験を優先する。

## やらないこと（スコープ外）

- ソーシャル機能全般（フォロー・いいね・コメント・公開・共有）
- マルチユーザー / チーム機能（1インスタンス＝1人）
- 外部へのデータ送信・解析（トラッキング、クラウド集計など）
- レコメンド・AI による自動分類（※将来的な補助機能としては検討余地あり、初期はなし）

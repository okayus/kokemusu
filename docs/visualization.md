# 可視化 ── このアプリの核心

「これまで自分が何をしてきたかをグラフィカルに見る」が目的。
苔のメタファー（[concept.md](concept.md)）を視覚に落とし込む。

## 1. タグ別ヒートマップ（＝ GitHub の草、ただし苔）

最優先で作る可視化。

- 横軸：日付（週ごとの格子）、縦軸：曜日。GitHub の contribution graph と同形式。
- マスの濃淡＝その日の投稿数。色はタグの色（緑系の苔カラー）。
- **タグごとに1枚** 並べる。「英語の苔」「typescript の苔」が横に並ぶイメージ。
- 全タグ合算の「総草」ビューも。
- マスにホバー / タップで、その日の投稿一覧へ。

## 2. 累積グラフ（積み上げ）

「積み上げ」という要望の直接的な表現。

- タグ別の累積投稿数を **積み上げ面グラフ** で時系列表示。
- 全体が時間とともに分厚くなっていく ＝ 苔が堆積していく様子。
- 期間切り替え（月 / 年 / 全期間）。
- タグの表示 ON/OFF で見たい領域だけ重ねられる。

## 3. 苔の庭ビュー（メタファー直球の象徴的ビュー）

数値グラフとは別の、情緒的・象徴的な一覧。

- 各タグを「石」または「区画」として配置。
- 投稿量・継続度に応じて **苔の生え具合** が変化する（薄い苔 → びっしり繁茂）。
- 最近投稿のあるタグは瑞々しく、長く放置されたタグは乾いた表現に。
- SVG / Canvas で手描き。アプリの世界観を一目で伝える「顔」になる画面。
- パッと見て「今どの分野が育っているか / 枯れかけか」が直感で分かる。

## 4. ストリーク・継続指標

- タグ別の連続投稿日数（現在のストリーク / 最長ストリーク）。
- 「最後に書いてから N 日」。枯れかけタグへのそっとしたリマインド（通知ではなく表示のみ）。
- 月間アクティブ日数（その月に何日書いたか）。

## 5. 内訳・分布

- タグ別投稿数の割合（円 / 棒）。期間で切り替え。
- 時間帯ヒストグラム（自分が何時に書きがちか）。
- 曜日別の傾向。
- タグの共起（同時に付けられやすいタグの組み合わせ）→ 一覧表ではなくグラフとして見せる（[§6](#6-タグ関係グラフ共起ネットワーク)）。

## 6. タグ関係グラフ（共起ネットワーク）

「自分の関心領域がどう繋がっているか」を見る。石（タグ）同士を苔が橋渡ししているイメージ。

- ノード＝タグ（大きさ＝投稿数、色＝タグの色）、エッジ＝同じ投稿に一緒に付いた回数（太さ＝共起回数）。
- 期間で絞れる（今月 / 今年 / 全期間）。時間とともに橋が太くなる・新しい橋が架かるのを眺める。
- ノードをタップでそのタグのヒートマップへ、エッジをタップで両方のタグが付いた投稿一覧へ。
- 本文は使わない（`post_tags` だけ）。暗号化と両立（[data-model.md](data-model.md) の共起クエリ）。
- 実装は自作 SVG。タグ数十〜百程度なら力学レイアウトも自前の単純な反復で足りる。増えたら共起回数の下限でエッジを間引く。
- タグ運用の判断材料にもなる: 常に一緒に付いている 2 タグは統合候補、孤立したタグはアーカイブ候補（[features.md](features.md) §2）。

## 7. 振り返りダッシュボード

上記を組み合わせた「振り返り」ページ。

- 週次 / 月次 / 年次サマリー（投稿数、伸びたタグ、新しく生えたタグ）。
- 「今年の苔むす」── 年間まとめ（Spotify Wrapped 的な自分向け年次レビュー）。

## 実装方針

- 重いダッシュボードライブラリは入れず、まずは **自作 SVG + 軽量ヘルパ**。
  - ヒートマップ・累積グラフは SVG の矩形/パスで十分組める。
  - 必要になったら `visx` や `Observable Plot` など関数志向で軽いものを検討。
- 集計はサーバ側（タグ×日の集計クエリ）でやり、フロントは描画に専念。
  - 本文を暗号化する場合でも、**日時・タグはメタデータとして平文** にしておけば集計可能（[security.md](security.md) の方針）。
- カラーパレットは苔をテーマに（深緑〜黄緑〜枯れ茶のグラデーション）。ダークモード対応。

## 優先順位

1. タグ別ヒートマップ（MVP）
2. 累積グラフ
3. ストリーク・内訳
4. タグ関係グラフ（共起ネットワーク）
5. 苔の庭ビュー（世界観の象徴）
6. 振り返りダッシュボード / 年次まとめ
